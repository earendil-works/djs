## Log
- 2026-11-04: Coordinator accepted naming frame slots instead of a physical spill (D2731,
  refining D2720): the k temporaries past the locals are frame slots with fixed indexes
  per site; the map names every index (`Site::named_slots`: name, place, what it holds).
  A physical spill would change no dump and needs interpreter support for the throw
  path (a rejected await throws at the resume pc before any unspill runs).
- Format: `bindings`, `operands` and `loops` become one `slots: {name: value}`.
  Exporter writes slots in frame order; loader writes each by name into the index its
  own map gives, refuses unknown/missing/extra names; binding keys exact (`name@scope`
  only when shadowed). Role `exception` is named `for-await.exception` so no temporary
  can equal a binding's `name@scope`.

## Result
A suspended activation is `$dump.resume(fn, {at, awaiting, this, args, slots, queue})`:
`slots` names every slot of the frame (bindings, hidden locals the loader does not make,
temporaries `construct@offset`), and the loader fills frame indexes by name from its own
map, so dumps are independent of key order, push order and stack layout (D2731). The
operand stack still exists in memory at a suspension (see D2731 for why and what a
physical spill would buy). `loops` is gone already (loop records are named slots);
0192 moves them into real hidden locals.
